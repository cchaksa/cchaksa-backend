# 작업 문서 가이드

작업별 문서는 `docs/tasks/{GitHub 이슈 번호}/`에서 관리합니다.

- 여러 해석이나 설계 판단이 필요한 작업은 `design.md`에 결정과 근거를 기록합니다.
- 여러 단계의 실행이나 인수인계가 필요한 작업은 `plan.md`에 범위, 순서, 검증 결과를 기록합니다.
- 범위가 단순하고 명확한 작업은 별도 작업 문서를 만들지 않습니다.
- 발견 사항, 계획 변경, 검증 결과는 새 문서를 늘리지 않고 기존 `design.md` 또는 `plan.md`에 반영합니다.
- 새 작업에는 과거 Spec Kit 형식인 `spec-lite.md`, `spec.md`, `clarify.md`, `tasks.md`, `checklist.md`, `context-notes.md`를 만들지 않습니다.
